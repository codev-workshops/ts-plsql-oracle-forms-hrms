# HRMS Technical Debt Registry

Every entry below was verified by reading the cited source in full; line ranges refer to the files on `main`.
Secret material (the AES key literal in `PKG_SECURITY.pkb` line 7 and any credential values) is deliberately
**not** reproduced here.

Severity scale: **Critical** (exploitable / data loss), **High** (incorrect behaviour or blocks migration),
**Medium** (maintainability / correctness risk), **Low** (hygiene).

Repository-wide facts used below: 11 packages totalling 4,170 body lines (largest: `PKG_EMPLOYEE.pkb`
966, `PKG_PAYROLL.pkb` 897, `PKG_LEAVE.pkb` 673); 6 Forms, 7 triggers, 30 tables, 6 views, 29 sequences;
no `test/`, `tests/`, `spec/` directory and no utPLSQL/SQL*Plus test scripts anywhere in the tree.
